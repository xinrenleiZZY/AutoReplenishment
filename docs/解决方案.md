# 自动补货决策系统 — 解决方案

## 一、解决的核心问题

| 痛点        | 现状            | 解决方案              | 效果          |
| --------- | ------------- | ----------------- | ----------- |
| 计算步骤复杂    | 运营手工收集10+项数据  | 系统自动从领星API拉取全部数据  | 节省80%数据收集时间 |
| 人工判断偏差    | 依赖个人经验，标准不统一  | 统一评分模型+量化决策规则     | 决策一致性100%   |
| ASIN多无法管理 | 数百ASIN人力无法全覆盖 | 系统每天自动计算全部ASIN    | 千级ASIN分钟级完成 |
| 断货风险发现晚   | 发现时已来不及补货     | 库存覆盖周期预警+提前采购窗口计算 | 提前30-60天预警  |
| 季节产品预测难   | 缺乏数据支撑，凭感觉备货  | 季节曲线模型+相似产品样本池    | 科学计算备货量     |

## 二、用户使用流程

### 日常使用（运营人员）

```
每天早上
    │
    ▼
打开飞书查看「采购日报」
    │
    ├── 立即采购列表 → 逐个确认 → 创建采购单
    │                    │
    │                    └── 不认可 → 调整数量/暂缓 → 系统记录偏差
    │
    ├── 观察列表 → 快速浏览 → 关注可能升级的ASIN
    │
    └── 暂停列表 → 跳过（系统已自动过滤）
    │
    ▼
确认完毕，当天工作完成（15-30分钟）
```

### 新ASIN接入流程

```
上架新产品
    │
    ▼
录入产品档案 (ASIN/分类/节日/工期等)
    │
    ▼
系统自动开始收集数据
    │
    ▼
7天后 → 进入启动期 → 系统给出首个小批量采购建议
```

## 三、核心价值

### 3.1 效率提升

- **数据采集自动化**：无需人工登录领星导出报表
- **计算自动化**：千级ASIN分钟级完成全部计算
- **报告自动化**：每日自动生成采购日报推送飞书

### 3.2 决策质量提升

- **量化评分**：6维度加权评分，告别凭感觉决策
- **统一标准**：所有ASIN同一套计算逻辑
- **提前预警**：断货风险提前30-60天发现
- **批次规划**：季节产品自动拆分多批，降低风险

### 3.3 管理提升

- **数据可追溯**：每次计算有完整记录，可复盘优化
- **持续学习**：记录人工调整，持续优化模型
- **规模化**：支持千级到万级ASIN的管理

## 四、关键场景示例

### 场景1：老品自动补货（圣诞毛毡树）

```
产品信息：S级爆款，圣诞装饰品，核心销售月8-12月
系统计算过程：
1. 生命周期 → 热卖期
2. 去年11月销量20000 → 趋势修正+20% → 24000
3. 当前库存18000，库存覆盖45天
4. 补货周期15天(工期)+30天(海运)+0(安全)=45天
5. 库存覆盖(45天) = 补货周期(45天) → 触发采购
6. 未来3月需求25000 + 安全库存3000 - 当前库存18000 = 10000
7. 评分94分 → 立即采购
```

### 场景2：新品上线（万圣节装饰）

```
产品信息：新品，万圣节装饰品，暂无历史销量
系统处理：
1. 生命周期 → 启动期（新品默认）
2. 找4个同类万圣节装饰品建立季节曲线
3. 7月实际卖出20套 → 反推年预计2000套
4. 按季节占比分配：8月60, 9月120, 10月400
5. 8月实际卖了90套 > 预测60套 → 自动上调后续预测
6. 给出小批量采购建议 → 验证市场反应
```

### 场景3：断货预警

```
某ASIN库存覆盖只剩20天，而补货周期需要52天
→ 系统评分：断货风险100分(权重25%)
→ 综合评分：75分 → 观察列表
→ 同时触发「断货预警」推送
```

## 六、风险控制

### 系统层面

- **建议模式**：系统仅提建议，最终采购由人确认
- **参数可调**：评分权重、运输时效等配置均可手动调整
- **手动兜底**：支持手动触发单ASIN计算/批量计算

### 业务层面

- **分批采购**：季节产品不一次性下完，根据销售动态调整
- **安全库存**：预留可配置的安全库存天数
- **利润过滤**：利润低于阈值自动暂停采购建议
