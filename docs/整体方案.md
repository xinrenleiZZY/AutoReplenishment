# 自动补货决策系统 — 整体方案

## 一、系统定位

自动补货决策系统是一个**AI驱动的采购决策平台**，将运营人员从繁琐的人工计算中解放出来。

**核心目标：** 系统自动完成数据采集 → 分析预测 → 决策评分 → 建议输出，运营只需 **查看建议 → 判断 → 确认采购**。

---

## 二、核心流程

```
数据采集层
    │
    ▼
产品基础数据 ──→ 生命周期识别 ──→ 历史销量分析 ──→ 季节曲线模型
                                                      │
                    ┌──────────────────────────────────┘
                    ▼
              未来销量预测 (老品4因素 / 新品季节曲线)
                    │
                    ▼
              销售时间轴判断 ──→ 库存健康分析 ──→ 库存覆盖周期计算
                    │
                    ▼
              采购触发判断
                    │
                    ▼
              建议采购数量 ──→ 采购批次规划 ──→ 采购评分模型
                    │
                    ▼
              AI采购建议 → 采购日报 → 飞书群通知
```

## 五、核心计算逻辑

### 5.1 未来销量预测（老品）

```
预测销量 = 去年同月销量 × 趋势系数(25%) × 市场系数(15%) × 广告系数(10%) × Listing系数(10%)
```

### 5.2 未来销量预测（新品）

```
预测销量 = 季节需求曲线占比 × 年预测总量 × 趋势系数 × 广告系数 × Listing系数
```

### 5.3 采购评分模型

```
总分 = 断货风险×25% + 销量趋势×25% + 利润空间×20% +
       生命周期×10% + 库存紧急×10% + 运输可达×10%

≥ 80分 → 立即采购
60-79分 → 观察
< 60分 → 暂停采购
```

### 5.4 采购数量计算

```
建议数量 = 未来N月预测需求 + 安全库存 - 当前可用库存
最终数量 = 向上取整至(装箱数量倍数) 且 ≥ 最低采购量
```

## 六、关键设计原则

1. **渐进式复杂**：MVP先跑通核心链路，再逐步优化模型精度
2. **可观测性**：每次计算记录完整链路日志，人工可追溯
3. **人工兜底**：系统建议 → 人工确认 → 执行，保留最终判断权
4. **持续学习**：记录"建议 vs 实际"的偏差，持续优化模型参数
