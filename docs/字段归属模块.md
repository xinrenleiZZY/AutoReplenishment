## Phase 2：核心计算引擎

### 2.1 产品生命周期识别

**用途：** 判断产品处于 启动期/增长期/热卖期/成熟期/下降期/清库存期

| 字段 | 状态 | 数据来源 | 用途说明 |
|------|:----:|---------|---------|
| 上架时间 | ✅ | 产品爬虫 `open_date` | 判断新品/老品 |
| 分类 | ✅ | 产品爬虫 `category_text` | 同类产品对比 |
| 品牌 | ✅ | 产品爬虫 `seller_brand` | 品牌维度参考 |
| 款名/SPU | ✅ | 产品爬虫 `product_relation_id` | SPU级别聚合 |
| Listing标签 | ✅ | 标签爬虫 `tags_full.json` | 节日/季节归类 |
| 自动标签 | ✅ | 标签爬虫 `tags_full.json` | 自动归类 |
| 7天销量 | ✅ | 产品爬虫 `seven_volume` | 短期销量判断 |
| 14天销量 | ✅ | 产品爬虫 `fourteen_volume` | 中期销量判断 |
| 30天销量 | ✅ | 产品爬虫 `thirty_volume` | 长期销量判断 |
| 销量环比 | ⏳ | 日快照(30天后) | **增长率计算（核心判断依据）** |
| 趋势图 | ✅ | 趋势分析 `sales_trend.py` | 走势可视化 |
| 大类排名 | ✅ | 产品爬虫 `category_rank.rank` | 市场表现监控 |
| 评分 | ✅ | 产品爬虫 `stars` | 产品质量维度 |

| 留评率 | 🔄 | 计算：评论数÷总销量 | 产品质量反馈 |
| 退款率 | ❌ | 领星利润API | 产品问题判断 |
| 订单量 | ❌ | 领星其他API | 订单vs销量关系 |
