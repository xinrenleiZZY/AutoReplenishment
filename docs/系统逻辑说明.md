## 三、数据处理流程

### 3.1 产品生命周期识别 ([lifecycle.py](file:///e:\ZY2026\yy021-自动补货决策系统\app\services\lifecycle.py))

```
输入: ASIN
            │
      ┌─────┴─────┐
      │ 是否新品?  │  ← 上架日期 ≤ 365天
      └─────┬─────┘
       新品/│\老品
           │
     ┌─────┴─────┐
     │ 默认启动期  │  ← 新品直接返回
     └───────────┘
           │
      ┌────┴────┐
      │计算增长率│  ← (近30天销量 - 30~60天前销量) / 30~60天前销量
      └────┬────┘
           │
      ┌────┴──────────────────────────────────────┐
      │  增长率 ≥ 50% 且 销量>100 → 热卖期        │
      │  增长率 ≥ 50%               → 增长期        │
      │  增长率 ≥ 20%               → 热卖期        │
      │  增长率 -20%~20%            → 成熟期        │
      │  增长率 -50%~-20%           → 下降期        │
      │  增长率 < -50%              → 清库存期      │
      └─────────────────────────────────────────────┘
```

**关键阈值：**
| 判断项 | 阈值 | 说明 |
|-------|------|------|
| 新品判定 | 上架 ≤ 365天 | 1年内为新品 |
| 增长率高速 | ≥ 50% | 增长期/热卖期分界 |
| 增长率中速 | ≥ 20% | 热卖期 |
| 增长率稳定 | -20%~20% | 成熟期 |
| 增长率下降 | -50%~-20% | 下降期 |
| 增长率清库存 | < -50% | 清库存期 |
| 热卖期附加条件 | 销量>100且增长率≥50% | 从增长期升级为热卖期 |

### 3.3 历史销量分析 ([sales_analysis.py](file:///e:\ZY2026\yy021-自动补货决策系统\app\services\sales_analysis.py))

| 分析维度 | 方法 | 阈值 |
|---------|------|------|
| 同比增长率 | (今年月销量 - 去年同月) / 去年同月 | - |
| 环比增长率 | (本月销量 - 上月) / 上月 | - |
| 7天/14天/30天趋势 | 对比各周期销量变化 | 增长≥30%/下降≥30% |
| 旺季月份判断 | 月销量 ≥ 月均×1.5 | 旺季阈值 1.5倍 |
| 淡季月份判断 | 月销量 ≤ 月均×0.5 | 淡季阈值 0.5倍 |

### 3.4 未来销量预测 ([forecast.py](file:///e:\ZY2026\yy021-自动补货决策系统\app\services\forecast.py))

**老品预测模型：**
```
预测销量 = 历史同期销量 × 综合修正系数

综合修正系数 = 1 + (趋势系数-1)×25% + (市场系数-1)×15%
                 + (广告系数-1)×10% + (Listing系数-1)×10%
```

| 系数 | 权重 | 数据来源 | 当前状态 |
|------|:----:|---------|:-------:|
| 趋势系数 | 25% | 近30天销量增长率 | ✅ 需日快照积累 |
| 市场系数 | 15% | 关键词排名+类目排名变化 | ✅ 有排名数据 |
| 广告系数 | 10% | ACOS+广告订单占比 | ❌ 需广告API |
| Listing系数 | 10% | 评分+Review增长 | ✅ 有评分/评论数 |

**新品预测模型：**
```
预测销量 = 季节曲线月占比 × 年预测总量 × 趋势系数 × 广告系数 × Listing系数
```

| 输入 | 说明 | 状态 |
|------|------|:----:|
| 季节曲线月占比 | 同类成熟产品的月度销量分布 | ✅ 系统配置 |
| 年预测总量 | 反推：7天实际销量÷1%，或默认2000 | ✅ 可计算 |
| 趋势/广告/Listing系数 | 同老品模型 | ❌ 部分待补充 |

### 3.5 库存健康分析 ([inventory_analysis.py](file:///e:\ZY2026\yy021-自动补货决策系统\app\services\inventory_analysis.py))

```
可用库存 = FBA可售 + FBA预留 + FBA在途 + 本地库存 + 采购单待到货

库存覆盖天数 = 可用库存 / 日均销量

补货周期 = 大货工期 + 运输时间（2026-08-04 起按分类工期表匹配）

运输时间（系统配置）:
  海运: 淡季30天 / 旺季45天
  空派: 淡季10天 / 旺季15天
  快递: 淡季3天 / 旺季6天
  淡季=1-7月, 旺季=8-12月
```

### 3.6 采购触发判断

```
条件: 库存覆盖天数 < 海运补货周期
  → 需要采购（推荐运输方式：<快递周期→快递, <空派周期→空派, 否则海运）
  → 不需要采购

紧急程度:
  库存覆盖 < 15天  → 紧急
  15~30天          → 需关注
  30~90天          → 正常
  >90天            → 库存充足
```

### 3.7 建议采购数量 ([purchase_calc.py](file:///e:\ZY2026\yy021-自动补货决策系统\app\services\purchase_calc.py))

```
建议数量 = 未来3个月预测需求 - 当前可用库存（2026-08-04 更新）
最终数量 = 向上取整至(装箱数量倍数)，如 10000/300=33.33 → 34箱
节日产品: 额外用 new_product_policy 节日窗口补货策略，取较大值
```

### 3.8 采购批次规划 ([purchase_calc.py](file:///e:\ZY2026\yy021-自动补货决策系统\app\services\purchase_calc.py))

| 条件 | 首批比例 | 第二批 |
|------|:-------:|:------:|
| 增长趋势 | 60% | 40%，30天后 |
| 稳定/季节性 | 50% | 50% |
| 下降趋势 | 40% | 60%（降低风险） |
| 非季节/小量/短周期 | 100% | 不分批 |

### 3.9 采购决策评分 ([scoring.py](file:///e:\ZY2026\yy021-自动补货决策系统\app\services\scoring.py))

```
综合评分 = Σ(各维度得分 × 权重)
```

| 维度 | 权重 | 评分规则 | 数据状态 |
|------|:----:|---------|:-------:|
| 断货风险 | 25% | 库存/周期≤20%→100分, ≤50%→80分, ≤80%→60分, ≤100%→30分, >100%→0分 | ✅ 可计算 |
| 销量趋势 | 25% | 增长≥30%→100分, ≥10%→80分, ±10%→60分, ≥-30%→40分, <-30%→20分 | ⏳ 需30天积累 |
| 利润空间 | **20%** | 毛利率≥30%→100分, ≥25%→80分, ≥20%→60分, ≥15%→40分, ≥10%→20分, >0%→10分, ≤0%→0分 | ❌ 需利润API |
| 生命周期 | 10% | 热卖期→100分, 增长期→90分, 成熟期→70分, 启动期→60分, 下降期→30分, 清库存→0分 | ✅ 可计算 |
| 库存紧急 | 10% | ≤15天→100分, 15~30天→80分, 30~90天→40分, >90天→0分 | ✅ 可计算 |
| 运输可达 | 10% | 海运可达→100分, 空派→80分, 快递→60分, 来不及→0分 | ✅ 系统配置 |

**决策等级：**
| 总分 | 决策 | 说明 |
|:----:|:----:|------|
| ≥ 80分 | **立即采购** | 建议尽快下单 |
| 60~79分 | **观察** | 可暂缓，持续监控 |
| < 60分 | **暂停采购** | 不建议采购 |

## 四、数据维度总结

### 4.1 时间维度

| 维度 | 用途 | 涉及模块 |
|------|------|---------|
| 日 | 昨日销量、库存快照 | 日报、采购触发 |
| 7天 | 短期趋势、日均销量 | 生命周期、库存分析 |
| 14天 | 中期趋势 | 生命周期、销量分析 |
| 30天 | 长期趋势、增长率 | 生命周期、销量预测 |
| 月 | 月度汇总、季节曲线 | 销量分析、预测 |
| 年 | 同比、产品等级 | 销量分析、等级计算 |

### 4.2 产品维度

| 维度 | 分类 | 用途 |
|------|------|------|
| 新品/老品 | 上架≤1年/≥1年 | 生命周期默认值、预测模型选择 |
| 生命周期 | 启动/增长/热卖/成熟/下降/清库存 | 评分、批次规划 |
| 产品等级 | S/A/B/C/D | 分类管理 |
| 季节性 | 是/否 | 批次规划、曲线模型 |

### 4.3 库存维度

| 维度 | 数据 | 用途 |
|------|------|------|
| FBA可售 | `afn_fulfillable_quantity` | 核心库存判断 |
| 在途 | `afn_inbound_shipped_quantity` | 补货到达预期 |
| 可用库存 | 可售+预留+在途+本地+采购单 | 补货计算基准 |
| 库存天数 | 可用库存÷日均销量 | 断货风险、采购触发 |

### 4.4 运输维度

| 方式 | 淡季 | 旺季 | 说明 |
|:----:|:----:|:----:|------|
| 海运 | 30天 | 45天 | 成本最低，时间最长 |
| 空派 | 10天 | 15天 | 折中方案 |
| 快递 | 3天 | 6天 | 成本最高，速度最快 |
