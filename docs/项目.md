### 关键计算规则（2026-08-04 版本）

| 规则 | 实现 |
|------|------|
| 补货周期 | 大货工期（分类工期表匹配，兜底30天）+ 运输时间 |
| 运输时间 | 海运淡30/旺45、空派淡10/旺15、快递淡3/旺6（8-12月旺季） |
| 建议采购量 | 未来3个月需求 - 当前库存，向上取整箱规倍数 |
| 评分 | 断货25%+销量25%+利润20%+生命10%+库存10%+运输10%，≥80立即采购/≥60观察/<60暂停 |
| 预测模型 | 老品=历史40%+趋势25%+市场15%+广告10%+Listing10%；新品=季节曲线×年总量 |
| 计算频率 | S每天 / A每3天 / B每5天 / C每7天 / D每14天，`CALC_FREQUENCIES` 可自定义 |
