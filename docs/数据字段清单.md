### 来源详细说明

```
领星 product/showOnline API
  ├── item_name         → product_name     ✅ 已导入
  ├── open_date         → list_date        ✅ 已导入
  ├── category_text     → category/sub_category  ✅ 已导入
  │   例: "纸质印刷类\纸质套装类" → category="纸质印刷类", sub_category="纸质套装类"
  ├── product_type      → product_type     ✅ 已导入 (1=长期产品, 2=节日产品)
  ├── principal_realname → operator        ✅ 已导入
  └── 以下字段在JSON中但尚未导入products表:
       ├── afn_fulfillable_quantity      → 用于 inventory_snapshots
       ├── afn_reserved_quantity         → 用于 inventory_snapshots
       ├── afn_inbound_shipped_quantity  → 用于 inventory_snapshots
       ├── total_volume / thirty_volume  → 用于 sales_data / 销量分析
       ├── reviews_num / stars           → 用于生命周期判断
       └── yesterday_spend / thirty_spend → 用于广告系数

领星 getAdjustPricing API (标签)
  └── tagInfos[].tagName → 可提取"圣诞节""万圣节"等节日标签 → 用于确定 festival 字段
      例: tagName="夏季类", tagName="25年"
      脚本已写好 → scraper/lingxing_tag_scraper.py
      需运行: python scraper/lingxing_tag_scraper.py

产品分类工期表 (Excel → category_leadtimes 表)
  └── 已导入60条分类工期数据
  └── 需代码自动匹配: products.category + sub_category → lead_time
      例: 分类"毛毡类/毛毡类" → 工期10-15天 → lead_time=15 (取最大值)

卖家精灵 MCP → 历史销量明细数据 → sales_data 表
SIF MCP → 广告数据 → 生命周期判断系数
```

## 二、销量数据（sales_data 表）

| # | 字段 | 数据库字段 | 来源 | 状态 |
|:-:|------|-----------|------|:----:|
| 1 | ASIN | `asin` | — | — |
| 2 | 销售日期 | `date` | 卖家精灵 MCP | ❌ 待对接 |
| 3 | 销量 | `sales_qty` | 卖家精灵 MCP | ❌ 待对接 |
| 4 | 销售额 | `sales_amount` | 卖家精灵 MCP | ❌ 待对接 |

**注意**：领星 `showOnline` 只提供**汇总数据**（30天总销量、日均销量），不提供**每日明细**。
需要卖家精灵 MCP 提供按天的销量明细才能填入 `sales_data` 表。

**临时替代方案**：可用领星API的 `thirty_volume` + `average_thirty_volume` 做初步计算，但精度有限。
